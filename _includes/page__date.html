{%- comment -%} The "Updated" line. Two things were wrong with the theme's version: - The format was hardcoded to "%B %-d, %Y", so a Korean site printed "April 13, 2026" here while the meta line above it printed 2026년 4월 13일. - It fell back to page.date when last_modified_at was absent, labelling the publication date as an update. With the publication date now shown in the meta line, that made the same date appear twice, once mislabelled. So it renders only when there is a real modification date, and only when that date actually differs from publication. No icon (spec 4.5.1): the Font Awesome calendar came from a deferred sheet the redesign removes, and the label already says what the date is.

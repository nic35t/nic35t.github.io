{%- comment -%} "함께 읽을 글" (spec 4.5.1, C13): four compact tiles after the article. The theme's `site.related_posts` is the newest posts unless lsi is on, which GitHub Pages never runs, so "related" meant "recent" and often led away from the topic. Now: the post's first category newest-first, then the newest posts site-wide to fill up to four, never the post itself, never twice. Deduplication keeps a "|url|url|" string and asks `contains "|url|"`. The bars make it an exact match (one URL can be a prefix of another), and it is plain string work, which behaves the same under Liquid 4.0.4 on GitHub Pages as it does locally. Variable names carry an `rp_` prefix because Liquid includes share the page's scope. Compact tiles have no eyebrow (spec 4.2): four posts from one category would print the same label four times.

{%- comment -%} One-shot font swap (spec 4.9). Inline and right after theme-init, so the class is on before any stylesheet can ask for a font. Pretendard's dynamic subset is ~92 unicode-range files. Each lands on its own and reflows the text it covers: measured on a post at 1440 under Slow 4G and 4x CPU, that staging cost CLS 0.165, against 0.098 for the old static build. This holds the system face (html.wf-wait swaps the two font tokens to system stacks) until every subset this page's text needs has loaded, then changes face once: 0.061. The `html.wf-wait` selector is (0,1,1) and beats the tokens' `:root` (0,1,0) wherever it sits. Nothing else may style html.wf-wait. No-JS readers get plain `font-display: swap`. {%- endcomment -%}

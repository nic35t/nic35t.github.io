{%- comment -%} One-shot font swap (spec 4.9). Inline and right after theme-init, so the class is on before any stylesheet can ask for a font. Pretendard's dynamic subset is ~92 unicode-range files. Each lands on its own and reflows the text it covers: measured on a post at 1440 under Slow 4G and 4x CPU, that staging cost CLS 0.165, against 0.098 for the old static build. This holds the system face (html.wf-wait swaps the two font tokens to system stacks) until every subset this page's text needs has loaded, then changes face once: 0.061. The swap is only allowed in the first 300ms. A single swap still reflows every line, and Pretendard is narrower than the fallbacks, so line counts change: the home header and a long post title each lost a line and pulled everything below up (CLS 0.29 at 375, 0.12 at 1440, routed font, Slow 4G). Inside 300ms the font is in practice coming from cache, so the swap lands around first paint rather than on a page someone is reading. Later than that, this view keeps the system face and the files warm the cache for the next page: font-display: optional, done by hand because the subsets must still arrive as one. The `html.wf-wait` selector is (0,1,1) and beats the tokens' `:root` (0,1,0) wherever it sits. Nothing else may style html.wf-wait. No-JS readers get plain `font-display: swap`. {%- endcomment -%}

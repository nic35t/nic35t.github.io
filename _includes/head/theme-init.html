{%- comment -%} Applies the saved theme before the page paints. This has to be inline and in : any later and the browser paints the system theme first and then swaps, which is the white flash every dark-mode site is judged on. No stored choice means no attribute, and the CSS falls back to prefers-color-scheme — the system setting stays the default. A stored choice also repaints the browser chrome. The two theme-color metas above this include each carry a media query, so on their own they follow the system; a reader who chose dark on a light system would get a light status bar over a dark page. Both are set to the chosen bar colour (--nav-bg-solid: #161617 dark, #fbfbfd light) so whichever one the browser picks agrees. {%- endcomment -%}
